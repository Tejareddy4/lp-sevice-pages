The form was redirecting users to a thank-you page after submission instead of staying on the same page.

Root Cause:
The form was using a standard HTML POST action which navigates the page on submit. The hidden iframe target (zohoWebhookFrame) was not reliably preventing the redirect.

Fix:
Intercepted the form submission using JavaScript (preventDefault()), then sent the data to the Zoho webhook via fetch API with no-cors mode in the background. The page no longer navigates — instead, a success message appears below the form confirming submission. Data continues to reach Zoho CRM correctly.
